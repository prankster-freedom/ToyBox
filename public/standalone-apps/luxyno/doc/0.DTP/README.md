# DTP 全体設計書

Luxyno の Visualモード（Visual Stage）の誌面設計の全体方針を定める。feature 別の確定デザイン仕様は `features/`、ラフ案は `roughs/`、素材は `assets/` で管理する（dtp スキル）。

- 対象: Visualモードの文書表示（ヒーロー、スラブ、スラブ内の本文と図版の割り付け、ベクター装飾素材、および講演・展示でのインタラクティブ・スポットライト演出）。図の中の装飾（ノード・エッジ）は `FR-003` の 4 スタイルの定義に従い、本書では扱わない。
- 上位の方針: [プロダクトコンセプト](../1.SRS.md#11-プロダクトコンセプト)（Visualモードは見た目の品質を優先し、閲覧操作のリアルタイム性を保つ）、[ブランドコンセプト](../1.SRS.md#12-ブランドコンセプトluxyno--brand-concept-sheet)

## DTP-001 トーン＆マナー

- **世界観**: 展示パネル・カンファレンスのステージのように、1 章（`h2`）を 1 枚のパネル（スラブ）として見せる。章の内容に合った誌面の型（雛形）で割り付け、どの章も同じ箱に流し込んだ印象を与えない。
- **主従**: 1 枚のスラブの主役は 1 つに絞る（言いたいことの一文、要点の並び、手順、図）。主役は大きさ・色・余白で示し、過剰な装飾では示さない。
- **装飾の質感とベクター素材**: 角丸（スラブ 22px、カード 16px）、柔らかい影（不透明度 0.06〜0.12）、細い線（1〜2px）に加え、要所に専用設計のベクター装飾素材（`AST-005` ヒーロー・プリズムエンブレム、`AST-006` ステートメント引用モニュメント、`AST-007` 要点カード・コーナーファセット、`AST-008` 手順フロー・方向シェブロン）を配し、簡易ビューアーの CSS 装飾では出せない細部の質感を仕立てる（`RGH-006`）。
- **静的な紙面に限定しないライブステージ性**: イベントや講演の現場で聴衆の視線を誘導できるよう、ホバー時の繊細な質感応答、クリックによる **インタラクティブ・スポットライト**（要点カードの注目、手順ステップの進行ハイライト、STAGE バッジによるスラブ注目）、製品名「Luxyno（Lux＝光）」を象徴する **シグナル・ライト（図の構造に沿って上流から下流へ伝わり、届いたノードが反応する光）**、および章を 1 シーンとして全画面で見せる **ステージ発表**、発表中に全シーンを実物のまま並べる **俯瞰（ライトテーブル）**、マウスの位置に光を当てる **光のポインター** を備える（`DTP-SHOW-070`, `080`, `DTP-VTPL-090`, `DTP-LIGHT-010`〜, `DTP-SHOW-010`〜, `RGH-007`, `008`, `RGH-010`〜`012`）。方向性を持たない無秩序な背景パーティクルは読解を損なうため行わない（`RGH-903`）。
- **表紙と表も誌面として仕立てる**: 文書の最初の 1 枚は、フロントマターと章の構成から組む表紙（`DTP-VTPL-100`）とし、展示パネルの扉として何の文書かと章の地図を示す。表は格子で囲まず、横の罫線と見出しの下のアクセントの線で組み、数値の列は右揃え・等幅の数字で桁をそろえる（`DTP-VTPL-110`）。簡易ビューアーの表示が最も残りやすい扉と表に、誌面の文法を通す（`RGH-013`, `RGH-101`）。
- **記法を増やさない**: 雛形とインタラクションはすべて標準の Markdown の記述パターンから自動で有効にする。独自の記法は設けない（`FR-015` と同じ方針。`RGH-901`）。

| 項目             | 値                                           | 備考                                 |

| ステージ外周余白 | `clamp(1rem, 3vw, 2.5rem)`                   |                                      |
| スラブ間         | `2.25rem`                                    |                                      |

## DTP-003 配色

雛形のアクセント色とベクター素材（`AST-005`〜`008`）の塗りは、インフォグラフィックスタイル（`FR-003`）ごとに 4 色（`--vs-c1`〜`--vs-c4`）を持ち、図の配色と同じ調子で誌面をまとめる。ブランドカラー（ダークスレート基調）は Visualモードの配色には使わない（[ブランドコンセプト](../1.SRS.md#12-ブランドコンセプトluxyno--brand-concept-sheet)）。ただし、発表の操作のための光（光のポインター、俯瞰の選択の輪。`DTP-SHOW-070`, `080`）は文書の中身ではなく Luxyno 自身の表現のため、ブランドのアクセントライト（ペールシアン・ルミナスホワイト）を使う。

| スタイル    | `--vs-c1` | `--vs-c2` | `--vs-c3` | `--vs-c4` | 調子の出どころ                               |
| :---------- | :-------- | :-------- | :-------- | :-------- | :------------------------------------------- |
| `shapes`    | `#E29578` | `#EBB453` | `#6CC4C9` | `#9CCB86` | Pastel Shapes のノードのグラデーション（コーラル、アンバー、アクア、ライム） |
| `cards`     | `#E29578` | `#E6B34B` | `#A3B4E4` | `#6DB1B4` | 2-Tier Cards の 4 色バー                     |
| `circles`   | `#D45D53` | `#7EA6BF` | `#ECB674` | `#7D9763` | Vibrant Circles の 5 色サークル（先頭 4 色） |
| `editorial` | `#D68C8C` | `#8FA876` | `#C9A66B` | `#8FA3B8` | Editorial Cream のダスティローズとセージ     |

- 文字に色を使うとき（カードの番号など）は、アクセント色 70% に、Light では濃紺（`#0F172A`）、Dark では白を 30% 混ぜた色（`color-mix`）にして、背景とのコントラスト比 3:1 以上（大きな太字の基準）を確保する。
- アクセント色を背景にした上の文字（手順の番号）は濃紺（`#1E293B`）とする。大きな太字（1rem 以上・800）のため、コントラスト比 3:1 以上を目安にする。
- 章番号のバッジ（`STAGE nn`）、ヒーローのプリズムエンブレム（`AST-005`）および 4 色バーも、この 4 色を使う。

## DTP-004 タイポグラフィ

| 要素                         | 書体                             | 大きさ                          | ウェイト | 行送り |
| :--------------------------- | :------------------------------- | :------------------------------ | :------- | :----- |
| ヒーローの題名（`h1`）       | Plus Jakarta Sans / Noto Sans JP | `1.25rem`〜`1.5rem`             | 800      | 1.25   |
| 章の見出し（`h2`）           | Plus Jakarta Sans / Noto Sans JP | `1.25rem`                       | 800      | —      |
| ステートメント（`DTP-VTPL-050`） | Plus Jakarta Sans / Noto Sans JP | `clamp(1.2rem, 2.2vw, 1.6rem)` | 700   | 1.6    |
| リード（`DTP-VTPL-020`）     | Inter / Noto Sans JP             | `clamp(1.1rem, 1.8vw, 1.35rem)` | 600      | 1.85   |
| カード・手順の番号           | Plus Jakarta Sans                | `1.75rem`（カード）/ `1.05rem`（手順） | 800 | 1    |
| カードの題（`DTP-VTPL-030`） | Inter / Noto Sans JP             | `1rem`                          | 700      | 1.5    |
| 本文                         | Inter / Noto Sans JP             | `1rem`（ブラウザの既定）        | 400      | 1.75   |

- ジャンプ率: 本文 1 に対し、ステートメント 1.2〜1.6、リード 1.1〜1.35。章の見出しより大きくなるのはステートメントだけで、章の主役が「その一文」であることを示す。
- 行の折り返し: ステートメントは `text-wrap: balance`、リードは `text-wrap: pretty` で、最後の行に 1〜2 文字だけが残る折り返しを避ける。雛形の文字（リード、カード、手順、ステートメント）は `word-break: auto-phrase` で文節の区切りで折り返し、「切り／替える」のような語の途中の改行を避ける（対応していないブラウザでは通常の折り返し）。禁則は `line-break: strict`（全体）に従う。
