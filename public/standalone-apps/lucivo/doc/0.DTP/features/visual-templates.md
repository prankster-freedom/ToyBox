# デザイン仕様: Visualモードの記述パターン別の雛形と動的ステージ演出（visual-templates）

Visualモードでは、文書を章（`h2`）ごとのスラブに分ける。本仕様は、スラブの中身の記述パターンを判定し、パターンに合った誌面の雛形・ベクター装飾素材で割り付けるとともに、講演・展示でのリアルタイムな視線誘導を支える動的ステージ演出を定める。全体の版面・配色・書体は [DTP 全体設計書](../README.md)（`DTP-001`〜`004`）に従う。

- 対応する要求: `FR-016`, `FR-017`, `FR-020`, `FR-021`（[visual-templates.md](../../1.SRS/features/visual-templates.md)）、`FR-015`（解説＋図版型）
- 採用したラフ: `RGH-001`〜`RGH-008`, `RGH-013`, `RGH-101`（[roughs/README.md](../roughs/README.md)）
- 使用する素材: フォント `AST-001`〜`AST-004`、ベクター装飾素材 `AST-005`〜`AST-008`（[assets/README.md](../assets/README.md)）

## DTP-VTPL-001 雛形の判定

スラブの「本文要素」（見出し `h2` とフロントマターを除く、スラブ直下の要素）を調べ、上から順に最初に当てはまる雛形を適用する。

| 順位 | 雛形                        | 記述パターン（条件をすべて満たす）                                  |
| :--- | :-------------------------- | :------------------------------------------------------------------ |
| 1    | 解説＋図版型（`split`）     | 図がちょうど 1 つあり、本文要素が 1 つ以上ある（`FR-015`）          |
| 2    | 標準型（`standard`）        | 図が 1 つ以上ある（1 位に当てはまらないもの）、または本文要素がない |
| 3    | リード型（`lead`）          | 本文要素が段落（`p`）だけで 1〜2 個、文字数の合計が 1〜160 字       |
| 4    | 要点カード型（`points`）    | 本文要素が「箇条書き（`ul`）1 つ」または「段落 1 つ＋箇条書き 1 つ」。項目が 2〜6 個で、どの項目も入れ子のリスト・コード・表・引用・チェックボックスを含まず 100 字以内 |
| 5    | 手順型（`steps`）           | 本文要素が「番号付きリスト（`ol`）1 つ」または「段落 1 つ＋番号付きリスト 1 つ」。項目が 2〜8 個で、項目の条件は 4 位と同じ |
| 6    | ステートメント型（`quote`） | 本文要素が引用（`blockquote`）1 つだけで、その中身が段落 1〜3 個、合計 240 字以内 |
| 7    | 標準型（`standard`）        | 上記のいずれにも当てはまらない                                      |

- 文字数は、要素の文字（`textContent`）の前後の空白を除いた長さで数える。
- 背景: 雛形は「一目で主役が分かる」量の内容にだけ使う。上限を超える長い段落・項目の多いリストを大きな文字やカードにすると、展示パネルとして読み切れない量になり、かえって品質が下がるため、標準型に戻す。
- 背景（小見出しを含む章）: `h3` などの小見出し、表、コード、ブロック数式を含む章は、構成が複合しているため標準型とする。

## DTP-VTPL-010 標準型（standard）

- これまでのスラブの組版（`FR-003` / `FR-009`）のまま。見出しの下に本文要素を上から順に流す。
- 雛形を適用しない章の受け皿であり、すべての Markdown 記法を見分けられる組版を保つ（`FR-009`）。

## DTP-VTPL-020 リード型（lead）

用途: 章の主張・概要を述べる短い文章（文書の冒頭の導入文など）。

```text
┌ STAGE 01  概要 ───────────────────────────────┐
│ ┃ Lucivo は、Markdown を展示品質の誌面に         │
│ ┃ 変換するビューアーです。                       │ ← 大きめ・太めの本文
└────────────────────────────────────────────────┘
  ┃ = 4 色のグラデーションの縦線（--vs-c1 → --vs-c4）
```

- 段落を 1 つのリードの枠（`.vs-lead`）にまとめ、左に幅 4px・角丸 2px の縦線（4 色のグラデーション）を引く。縦線と文字の間は `1.25rem`。
- 文字は `DTP-004` のリード（`clamp(1.1rem, 1.8vw, 1.35rem)`・600・行送り 1.85）、色は主文字色（`--text-primary`）。
- 2 つ目の段落との間は `0.75rem`。

## DTP-VTPL-030 要点カード型（points）

用途: 特長・要点・選択肢などの並列の項目。

```text
┌ STAGE 02  特長 ─────────────────────────────────────────┐
│ （導入の段落があれば、ここに通常の本文で置く）            │
│ ┌▀▀▀▀▀▀▀▀▀▀▀┐ ┌▀▀▀▀▀▀▀▀▀▀▀┐ ┌▀▀▀▀▀▀▀▀▀▀▀┐            │
│ │ 01      ◢ │ │ 02      ◢ │ │ 03      ◢ │  ▀ = 上端 4px の帯 │
│ │ 軽快       │ │ 展示品質   │ │ 記法そのまま│  ◢ = AST-007 コーナー透かし │
│ │ 説明文…    │ │ 説明文…    │ │ 説明文…    │            │
│ └────────────┘ └────────────┘ └────────────┘            │
└──────────────────────────────────────────────────────────┘
```

- 箇条書きをカードのグリッドにする。間隔は `1rem`。列の数は項目の数から決め、最後の行に 1 枚だけ残る端数を作らない。

  | 項目の数 | 列の数                                    |
  | :------- | :---------------------------------------- |
  | 2・3     | 項目の数と同じ（1 行）                    |
  | 4        | 2（2 × 2）。版面 56rem 以上では 4（1 行） |
  | 5・6     | 3                                         |

  版面 30rem 以下では 1 列にする。
- カード: 角丸 16px、内側の余白 `1.25rem`、背景は本文より一段明るい（Light `#F8FAFC` / Dark `rgba(15, 23, 42, 0.45)`）、枠線 1px、影 `0 6px 18px -8px rgba(15, 23, 42, 0.12)`。
- 上端に幅 4px の帯を付ける。帯の色は項目の順に `--vs-c1`→`--vs-c2`→`--vs-c3`→`--vs-c4` を繰り返す。
- **コーナーファセット装飾（`AST-007`）**: カードの右上に `.vs-card-ornament`（`56px × 56px`）を置き、`assets/motifs/card-corner-ornament.svg` を CSS `mask-image` で適用して項目のアクセント色（`--vs-c`）で塗る（通常時の不透明度 `0.55`、ホバー・スポットライト時は `0.95` に高まり微細に拡大する）。
- カードの先頭に 2 桁の番号（`01`, `02`…）を置く。`DTP-004` のカードの番号（1.75rem・800）、色は帯の色を濃く（Dark では明るく）した色（`DTP-003`）。
- 項目が「**題**: 説明」（太字の直後に `:` または `：`）で始まる場合は、太字を項目の題（1rem・700・主文字色）として番号の下に独立した行で置き、区切りの `:` は表示しない。
- 導入の段落がある場合は、カードの上に標準型の本文として置く。

## DTP-VTPL-040 手順型（steps）

用途: 手順・工程・時系列など、順序に意味のある項目。

```text
項目が 4 個以下で、版面の幅が 40rem 以上の場合（横並び）
   (1)━━ » ━━(2)━━ » ━━(3)━━ » ━━(4)   » = AST-008 方向シェブロン
  受け付ける   確認する    発注する    出荷する

項目が 5 個以上、または版面の幅が 40rem 未満の場合（縦並び）
   (1) 受け付ける
    ┃
   (2) 確認する
    ┃
   (3) …
```

- 番号付きリストを、番号の丸と接続線・方向シェブロン（`AST-008`）でつないだ手順図にする。
- 番号の丸: 直径 `2.5rem`、塗りは項目の順に `--vs-c1`〜`--vs-c4`、文字は濃紺（`#1E293B`、1.05rem・800）。丸の周りにスラブの背景色の輪（5px）を付け、接続線から浮かせる。
- 接続線: 太さ 2px、色は強い線の色（Light は `--border-strong`、Dark は `#64748B`）。丸の中心を結ぶ。
- **方向シェブロン素材（`AST-008`）**: 2 番目以降の各ステップ（`li:not(:first-child)`）に `.vs-step-chevron`（`14px × 14px`、`assets/motifs/step-arrow.svg` の `mask-image`）を置き、前のステップからの進行方向を示す（横並びでは左側の接続線上、縦並びでは 90 度回転して上側の接続線上）。
- 横並び: 項目を等幅の列に置き、丸の下に中央揃えで文字を置く。版面の幅（スラブの幅）で判定するため、`Split` 表示の狭いプレビューでも詰まらない。
- 縦並び: 丸を左に、文字を丸の右（左端から `3.5rem`）に左揃えで置き、項目の間隔は `0.9rem`。
- 導入の段落は、要点カード型と同じく手順の上に置く。

## DTP-VTPL-050 ステートメント型（quote）

用途: 理念・標語・引用など、その一文を見せたい章。

```text
┌ STAGE 03  フィロソフィー ──────────────────────────┐
│                     (( “ ))                         │ ← AST-006 彫刻引用モニュメント（--vs-c1）
│              構文に、光と舞台を。                    │ ← 中央揃えの大きな文字
│                — Lucivo のフィロソフィー             │ ← 出典（小さく、薄く）
└─────────────────────────────────────────────────────┘
```

- 引用の左線と左の余白を外し、最大幅 `46rem` で中央に置く。文字は `DTP-004` のステートメント（中央揃え、`text-wrap: balance`）。
- **引用モニュメント素材（`AST-006`）**: 上部中央（`::before`）に、システムフォントの文字ではなくベクター素材 `assets/motifs/quote-watermark.svg`（幅 `3.75rem`・高さ `2.6rem`、CSS `mask-image`、塗り `--vs-c1`）を置く。
- 最後の段落が `—`（全角ダッシュ）・`―`（水平線）・`--` で始まる場合は、出典として 0.875rem・600・薄い文字色（Light は `--text-muted`、Dark は `#94A3B8`）で置く。

## DTP-VTPL-060 解説＋図版型（split）

- `FR-015` の自動 2 段組み（本文 5 : 図版 7）。図が右の段に収まらない場合と、版面幅 768px 未満は 1 段組みになる。デザインは変えず、雛形の 1 つとして台帳に登録する（`RGH-005`）。

## DTP-VTPL-070 スタイル別の配色の適用とヒーローエンブレム

- 雛形のアクセント色、章番号のバッジ（`STAGE nn`）の塗り、ヒーローのプリズムエンブレム（`AST-005`、`.exhibition-hero-emblem`、`28px × 28px`）および 4 色バーは、選んでいるインフォグラフィックスタイルの 4 色（`DTP-003`）を使う。
- スタイルを切り替えると、図と同時に誌面のアクセント色とベクター素材の色もすべて切り替わる。

## DTP-VTPL-080 Dark の外観

- カードの背景・枠線、手順の丸の輪の色は、Dark のスラブの背景（`#1E293B`）に合わせる。アクセント色そのもの（帯・丸の塗り・ベクター素材）は Light と同じ色を使う。
- 文字の色は、主文字色・薄い文字色のトークン（`--text-primary` / `--text-muted`）に従う。ただし、Dark の `--border-strong`・`--text-muted` はスラブの背景に近いため、手順の接続線と引用の出典は明るい色にする（`DTP-VTPL-040`, `050`）。

## DTP-VTPL-090 動的ステージ演出・インタラクティブ・スポットライト

用途: 講演・カンファレンス・展示ブースでのライブ実演時に、聴衆の視線をいま説明している項目や章へリアルタイムに誘導する（`RGH-007`, `RGH-008`）。

1. **要点カードのスポットライト選択（`.vs-points > li`）**
   - 要点カードをクリックすると、そのカードに `.is-spotlight`、親の `ul.vs-points` に `.has-spotlight` が付く。
   - `.is-spotlight` のカードは `translateY(-4px)` で浮き上がり、枠線が `--vs-c`、光彩付きの影、コーナー装飾（`AST-007`）の不透明度が `0.95` になる。同じリスト内の他のカード（`:not(.is-spotlight)`）は不透明度 `0.48` に減光する。
   - 選択中のカードをもう一度クリックするか、`Escape` キーを押すと解除され、全カードが通常の表示に戻る（カード内のリンク `a` をクリックした場合はリンク遷移を優先し、スポットライトは切り替えない）。
2. **手順ステップの進行ハイライト（`.vs-steps > li`）**
   - 手順の項目 $k$ をクリックすると、その項目に `.is-spotlight`、先頭から $k$ 番目までの項目（$1 \dots k$）に `.is-reached`、親の `ol.vs-steps` に `.has-spotlight` が付く。
   - `.is-reached` の項目は番号の丸と方向シェブロン（`AST-008`）が強調され、`.is-spotlight`（現在地 $k$）の丸は `scale(1.14)` とアクセント光彩で際立つ。未到達の項目（$k+1$ 以降）は不透明度 `0.45` に減光する。
   - 選択中の項目（`.is-spotlight`）をもう一度クリックするか、`Escape` キーを押すと解除される。
3. **STAGE バッジによるスラブ注目モード（`.exhibition-num-badge`）**
   - スラブ見出しの `.exhibition-num-badge`（`STAGE nn`）をクリックすると、そのスラブ（`.exhibition-slab`）に `.is-stage-focused`、親の `.exhibition-wrap` に `.has-stage-focus` が付く。
   - `.is-stage-focused` のスラブは `--vs-c1` の強調枠と深い影で浮き上がり、他のスラブ（`:not(.is-stage-focused)`）は不透明度 `0.42` に減光する。
   - もう一度バッジをクリックするか、`Escape` キーを押すと解除される。
4. **ホバー時のマイクロインタラクションとリアルタイム性の維持**
   - カード・手順・ヒーローエンブレムは、ポインタのホバーに対して `0.2s`〜`0.25s` の滑らかなトランジションで応答する（`prefers-reduced-motion: reduce` 環境では動きを抑える）。
   - すべての動的演出はクラス操作と CSS トランジションだけで完結させ、描画時（`renderApp()`）に `getComputedStyle` やレイアウト計測を一切行わない（`NFR-006`, `NFR-007`）。

## DTP-VTPL-095 光の演出

手順の接続線と図の結線の上を流れる光は、シグナル・ライト（[stage-show.md](stage-show.md) の `DTP-LIGHT-010`〜`060`）に従う。

## DTP-VTPL-100 表紙（カバー）

用途: 文書の最初の 1 枚。展示パネルの扉・講演の表紙として、何の文書かを一目で伝え、章の地図を示す（`RGH-013`）。

```text
┌──────────────────────────────────────────────────────────┐
│ ░░ c1 の光だまり                          c3 の光だまり ░░ │ ← 上端の左右に静止した淡い光（13%）
│                         ◇                                  │ ← AST-005 プリズムエンブレム
│                     ▬▬ ▬▬ ▬▬ ▬▬                           │ ← 4 色バー
│            LUCIVO  /  VISUAL STAGE  /  TEMPLATES            │ ← アイブロウ（tags）
│              文書の題名を大きく、2 行までで                │ ← 題名（h1 → title → ファイル名）
│        description を 2〜3 行のリード文として置く          │ ← デック（description）
│  ────────────────────────────────────────────────────────  │
│  01 章の題          04 章の題          07 章の題           │ ← 目次（列の上から下へ）
│  02 章の題          05 章の題          08 章の題           │
│  03 章の題          06 章の題                              │
└──────────────────────────────────────────────────────────┘
```

| 要素 | 内容の出どころ | デザイン |
| :--- | :------------- | :------- |
| アイブロウ（`.vs-cover-eyebrow`） | フロントマターの `tags`（先頭の 4 個） | JetBrains Mono・`0.72rem`・600・字間 `0.18em`・大文字。区切りは `/`（不透明度 0.45）。色はアクセント `--vs-c1` を文字用に濃くした色（`DTP-003`） |
| 題名（`.vs-cover-title`） | `h1`、なければフロントマターの `title`、なければ読み込んだファイル名 | `clamp(1.75rem, 3.6vw, 2.6rem)`・800・行送り 1.25・字間 `-0.01em`・最大幅 `46rem`。`text-wrap: balance` と文節での折り返し |
| デック（`.vs-cover-deck`） | フロントマターの `description` | `1.05rem`・500・行送り 1.8・薄い文字色（Dark は `#CBD5E1`）・最大幅 `40rem` |
| 目次（`.vs-cover-agenda`） | 章（`h2`）の番号と題。章が 3〜15 個のときだけ | 上に 1px の罫線（`--vs-card-border`）。章が 6 個以下は 2 列、7 個以上は 3 列。列の上から下へ読む順に並べる。番号は Plus Jakarta Sans・`0.95rem`・800・等幅数字で、4 色を順に使う（`DTP-003`）。題は `0.875rem`・600 で 2 行まで（超える分は `…`）。版面 40rem 以下は 1 列 |

- 背景（静止した光だまり）: 表紙の上端の左右に `--vs-c1`・`--vs-c3` の淡い放射グラデーションを置き、スタイルの色の気配を表紙に持たせる。動かさない（`RGH-903`）。
- 目次の項目を押すと、その章の先頭までスクロールする。ホバー・フォーカスで項目の背景をその番号の色で 12% だけ染める。
- 目次の上限（15 章）: 16 章以上は 3 列でも 6 行を超え、表紙の主役（題名）が目次に埋もれるため出さない。2 章以下は地図にならないため出さない。
- アイブロウ・デックは、フロントマターに `tags`・`description` がない文書では出さない。独自の記法は設けない（`RGH-901`）。
- ステージ発表の表紙（`DTP-SHOW-020`）では、アイブロウを `0.95rem`、デックを `1.45rem`（最大幅 `52rem`）にし、目次は出さない。目次は閲覧時の道案内で、発表ではシーンを順に送るため（`RGH-108`）。

## DTP-VTPL-110 誌面の表

用途: 表を、エディトリアルデザインの「罫線で組む表」にする。セルを格子で囲む表計算ソフトの見た目をやめ、行と列を余白と横の罫線で読ませる（`RGH-101`）。

```text
 雛形           最小項目数   最大項目数   合計の上限      ← 見出し: 0.78rem・700
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━  ← 2px・--vs-c1
 リード型                1            2       160 字      ← 先頭の列は行の見出し（600・主文字色）
───────────────────────────────────────────────────  ← 1px・--vs-card-border
 要点カード型            2            6            —      ← 数値の列は右揃え・等幅の数字
───────────────────────────────────────────────────  ← 最後の行の下は強い線
```

- 縦の罫線は引かない。行の下に 1px の罫線（`--vs-card-border`）、最後の行の下は強い線（Light は `--border-strong`、Dark は `#64748B`）、見出しの行の下は 2px のアクセントの線（`--vs-c1`）とする。見出しの行の背景は塗らない。
