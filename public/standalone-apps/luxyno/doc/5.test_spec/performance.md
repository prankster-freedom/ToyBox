# テスト仕様: 起動と再描画の軽快さ（performance）

`NFR-006` の判定基準（応答時間の目標値）は未確定（Issue #16）のため、本仕様では、起動時に不要な読み込みをしないこと、キャッシュから表示するときに重い処理をやり直さないことを確かめる。再描画の時間は参考値として記録する。

| ID          | 観点 | 手順 | 期待結果 | 確認方法 | 対応 ID |
| :---------- | :--- | :--- | :------- | :------- | :------ |
| TC-PERF-001 | 起動時の読み込み | アプリを開き、図も数式もない文書を描画し、次に `sample.md` を読み込む | Tailwind の CDN を使わず、生成済みの `css/tailwind.css` で画面が組まれる。図も数式もない間は Mermaid・KaTeX を読み込まず、`sample.md` で読み込む | 自動 | NFR-006, DD-MATH-024 |
| TC-PERF-002 | 再描画のキャッシュ | `sample.md` の表示後に、もう一度描画する | Fit の計算結果と数式の描画結果がキャッシュから使われ、計算後のスタイルを調べ直さない（`getComputedStyle` の呼び出しが 0 回）。描画の時間を記録する | 自動 | NFR-006, DD-DIAG-034, DD-MATH-024 |
