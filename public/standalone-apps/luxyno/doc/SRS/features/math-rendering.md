# Feature Requirement Specification: math-rendering

本ドキュメントは、Luxyno における Markdown 本文および Mermaid 図内ラベルにおける TeX 数式描画に関する機能要求仕様を定義する。

対応する全体 SRS: [doc/SRS.md](../../SRS.md)

## 対象機能要求一覧

| ID     | 機能名     | 概要 |
| :----- | :--------- | :--- |
| FR-010 | 数式の描画 | 本文のインライン・ディスプレイ数式、およびフローチャート・シーケンス図のラベル内の数式を KaTeX 等で描画する |

---

## 機能要求の詳細

### FR-010: 数式の描画

- **本文中の数式記法**:
  - **インライン数式**: `$…$` で囲む。開きの `$` の直後および閉じの `$` の直前に空白を含まず、閉じの `$` の直後が数字でない場合に数式として認識する（`$5` や `$10` といったドル通貨表記の誤認を防止）。
  - **ブロック（ディスプレイ）数式**: `$$` だけの独立行で囲む。また、段落内の `$$…$$` も独立行のディスプレイ数式としてレンダリングする。
  - **エスケープ**: `\$` と記述した場合はエスケープされ、`$` 記号自体を文字として表示する。コード領域（インラインコード、コードブロック）内の `$` は数式化しない。
- **Mermaid 図内の数式**:
  - フローチャートおよびシーケンス図のノードラベル内に `$$…$$` で記述された数式を、Mermaid（`10.9.1`）の数式サポート機能と連携して描画する。
  - 数式描画時も線やノード枠、他のテキストと重ならず、Dark 外観でも視認性を損なわないこと。
- **エラー耐性とフォールバック**:
  - TeX 構文にエラーがある場合は、その数式部分のみをエラー表示とし、文書全体のパース・描画を中断しない。
  - 数式レンダラー（KaTeX）が読み込めない環境（オフライン等）では、元の TeX 記述テキストをそのまま表示する。
- **背景・根拠**: 技術仕様書や論文・プレゼンテーションでは数式表現が不可欠である。GitHub 等の標準 Markdown 記法に合わせた `$` / `$$` デリミタを採用し、互換性と学習コストゼロを両立する。
