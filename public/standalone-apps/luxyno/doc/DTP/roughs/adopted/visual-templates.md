# 採用ラフ: Visualモードの記述パターン別の雛形

確定した寸法・色は [features/visual-templates.md](../../features/visual-templates.md) を正とする。本書は検討時の構図の記録である。視線の流れを矢印（→ ↓）で示す。

## RGH-001 リード型

```text
┌────────────────────────────────────────────┐
│ STAGE 01  概要                              │ ① 見出し
│ ──────────────────────────────────────────  │
│ ┃ 大きめ・太めの本文で、章の主張を         │ ② 縦線から文字へ（↓）
│ ┃ 2〜4 行で述べる。                         │
└────────────────────────────────────────────┘
```

- 主役: 本文そのもの。装飾は左の縦線だけにし、文字の大きさで主役を示す。

## RGH-002 要点カード型

```text
┌──────────────────────────────────────────────────────┐
│ STAGE 02  特長                                         │
│ 導入の一文（任意）                                     │
│ ┌▀▀▀▀▀▀▀▀┐  ┌▀▀▀▀▀▀▀▀┐  ┌▀▀▀▀▀▀▀▀┐  ┌▀▀▀▀▀▀▀▀┐       │ Z 型に流れる
│ │01      │→ │02      │→ │03      │→ │04      │       │
│ │題      │  │題      │  │題      │  │題      │       │
│ │説明    │  │説明    │  │説明    │  │説明    │       │
│ └────────┘  └────────┘  └────────┘  └────────┘       │
└──────────────────────────────────────────────────────┘
```

- 主役: 項目の数と題。番号と上端の帯の色で、項目を数えやすくする。列の数は項目の数で決める（2・3 個は 1 行、4 個は 2 × 2、5・6 個は 3 列）。

## RGH-003 手順型

```text
横並び（4 個以下・版面 40rem 以上）
  (1)━━━━━(2)━━━━━(3)━━━━━(4)      → 左から右へ
  受付     確認     発注     出荷

縦並び（5 個以上・版面 40rem 未満）
  (1) 受付                          ↓ 上から下へ
   ┃
  (2) 確認
```

- 主役: 順序。丸と線でつなぎ、要点カード型（並列）との違いを形で示す。

## RGH-004 ステートメント型

```text
┌────────────────────────────────────────────┐
│                     “                       │ ① 引用符で目を引く
│        構文に、光と舞台を。                  │ ② 一文（中央）
│            — 出典                           │ ③ 出典
└────────────────────────────────────────────┘
```

- 主役: 一文。余白を大きく取り、講演のスライドの 1 枚のように見せる。

## RGH-005 解説＋図版型

```text
┌──────────────────────────────────────────────────────┐
│ STAGE 09  フローチャート                               │
│ ┌ 本文（5）──────┐  ┌ 図版（7）───────────────────┐ │
│ │ 解説の段落      │→ │                              │ │ F 型: 左で読み、右で確かめる
│ │ ・箇条書き      │  │        Mermaid の図          │ │
│ └────────────────┘  └──────────────────────────────┘ │
└──────────────────────────────────────────────────────┘
```

- `FR-015` で実装済み。図が右の段に収まらない場合は 1 段組みになる。
