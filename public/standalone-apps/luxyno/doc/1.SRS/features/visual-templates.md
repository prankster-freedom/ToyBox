# Feature Requirement Specification: visual-templates

本ドキュメントは、Luxyno の Visualモードで、章（スラブ）ごとの Markdown の記述パターンに応じて誌面の雛形（レイアウトとベクター装飾素材）を自動で切り替えるとともに、講演・展示でのライブ操作に向けた動的ステージ演出（インタラクティブ・スポットライト）を提供する機能要求仕様を定義する。

対応する全体 SRS: [doc/1.SRS.md](../../1.SRS.md)／デザイン仕様: [0.DTP/features/visual-templates.md](../../0.DTP/features/visual-templates.md)

## 対象機能要求一覧

| ID     | 機能名                             | 概要 |
| :----- | :--------------------------------- | :--- |
| FR-016 | Visualモードの記述パターン別の雛形 | Visualモードのスラブの記述パターン（短い段落、箇条書き、番号付きリスト、引用など）を判定し、パターンに合った雛形（リード、要点カード、手順、ステートメントなど）で表示する |
| FR-017 | Visualモードのベクター装飾素材と動的ステージ演出 | Visualモードのヒーロー・各雛形に専用ベクター装飾素材（`AST-005`〜`008`）を適用し、カード・手順・スラブのクリックによるインタラクティブ・スポットライトとホバー時の質感応答を提供する |

## 機能要求の詳細

### FR-016: Visualモードの記述パターン別の雛形

- Visualモードで、スラブ（`h2` ごとの章、および最初の `h2` より前の部分）の中身の記述パターンを判定し、次の雛形のいずれか 1 つで表示すること。判定の条件と優先順位、各雛形のデザインは、デザイン仕様（`DTP-VTPL-001`〜`080`）に従う。

  | 雛形             | 記述パターンの概要                                          | デザイン仕様   |
  | :--------------- | :---------------------------------------------------------- | :------------- |
  | 解説＋図版型     | 本文と 1 つの図（`FR-015`）                                 | `DTP-VTPL-060` |
  | リード型         | 短い段落（1〜2 個、合計 160 字以内）だけ                    | `DTP-VTPL-020` |
  | 要点カード型     | （導入の段落＋）入れ子のない短い箇条書き（2〜6 項目）       | `DTP-VTPL-030` |
  | 手順型           | （導入の段落＋）入れ子のない短い番号付きリスト（2〜8 項目） | `DTP-VTPL-040` |
  | ステートメント型 | 短い引用（段落 1〜3 個、合計 240 字以内）だけ               | `DTP-VTPL-050` |
  | 標準型           | 上記のいずれにも当てはまらない                              | `DTP-VTPL-010` |

- 雛形の適用で、本文の内容（文字、リンク、インラインの装飾、数式）を失わないこと。
- 雛形のアクセント色は、選んでいるインフォグラフィックスタイル（`FR-003`）に合わせて切り替えること。Light / Dark のどちらでも、文字・装飾が背景と見分けられること（`NFR-004` に準じる）。
- 高速モードの表示は変えないこと（`NFR-006`）。
- **背景・根拠**: Visualモードは講演資料・展示素材としての品質を目指す（[プロダクトコンセプト](../../1.SRS.md#11-プロダクトコンセプト)）。すべての章を同じ箱に上から流し込むと、章ごとの主役（主張の一文、要点の並び、手順）が見分けにくく、簡易ビューアーで描画した印象になる。誌面の設計で章の内容に合った型を使い分けるように、記述パターンから雛形を選ぶ。
- **背景・根拠（判定の上限）**: 長い段落や項目の多いリストを大きな文字やカードにすると、1 枚のパネルとして読み切れない量になり、品質が下がる。そのため、雛形は短い内容に限り、それ以外は標準型にする。
- **採らなかった案**:
  - 独自の記法（HTML コメントなど）で雛形を指定する案。文書が Luxyno 専用になり、Markdown の可搬性を損なうため（`FR-015` と同じ方針。`RGH-901`）。
  - 表・コード・図だけの章の専用の雛形。崩れない汎用の規則を決めきれない、または既存の装飾と重なるため、ストックとして保留した（`RGH-101`〜`104`）。

### FR-017: Visualモードのベクター装飾素材と動的ステージ演出

- **ベクター装飾素材の適用（`DTP-001`, `DTP-VTPL-030`〜`070`）**:
  - 本番同梱のベクター装飾素材（`assets/motifs/` 配下の `AST-005` ヒーロー・プリズムエンブレム、`AST-006` ステートメント引用モニュメント、`AST-007` 要点カード・コーナーファセット、`AST-008` 手順フロー・方向シェブロン）を Visualモードの該当要素に表示し、選択中のインフォグラフィックスタイルの配色（`--vs-c1`〜`--vs-c4`）に連動させること。
- **インタラクティブ・スポットライト（`DTP-VTPL-090`）**:
  - **要点カードのスポットライト**: 要点カード（`.vs-points > li`）をクリックすると、そのカードを浮き上がらせて強調（`.is-spotlight`）し、同じリスト内の他のカードを減光すること。もう一度クリックするか `Escape` キーで解除できること。
  - **手順ステップの進行ハイライト**: 手順の項目（`.vs-steps > li`）の $k$ 番目をクリックすると、1〜$k$ 番目を到達済み（`.is-reached`）、$k$ 番目を現在注目（`.is-spotlight`）として強調し、$k+1$ 番目以降を減光すること。もう一度クリックするか `Escape` キーで解除できること。
  - **スラブのステージフォーカス**: スラブ見出しの `STAGE nn` バッジ（`.exhibition-num-badge`）をクリックすると、そのスラブを注目強調（`.is-stage-focused`）し、他のスラブを減光すること。もう一度クリックするか `Escape` キーで解除できること。
- **リアルタイム性の維持（`NFR-006`, `NFR-007`）**:
  - スポットライトの切り替えやホバー応答は即座に反応し、再描画（`renderApp()`）や `getComputedStyle` の呼び出しを発生させないこと。
- **背景・根拠**:
  - 簡易ビューアーの CSS 枠線やシステムフォントの記号だけでは「トップデザイナーが制作した細部の質感」に届かないため、専用設計のベクター素材（`AST-005`〜`008`）を同梱して質感を高める（`RGH-006`）。
  - また、Luxyno の Visualモードは紙の印刷物ではなく、イベント・講演・展示会場の画面でリアルタイムに操作・閲覧されるビューアーである。発表者がいま説明しているカード・工程・章をクリック 1 つで聴衆に示す「ライブステージとしての動的演出」を備えることで、静的な表示にとどまらない価値を訴求する（`RGH-007`, `RGH-008`）。
- **採らなかった案**:
  - 常時ループする背景パーティクルや光彩アニメーション（`RGH-903`）。何も操作していない間も画面が動き続けると、文書の読解を妨げ、常時 GPU 負荷が発生して閲覧のリアルタイム性を損なうため採らない。
