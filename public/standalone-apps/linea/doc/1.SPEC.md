# 要求仕様書 (1.SPEC.md)

## 1. 概要

**Linea — Visual Markdown & Diagram Studio** は、Markdown 文書と Mermaid ダイアグラムをリアルタイムに編集・プレビュー・エクスポートできるスタンドアロンの Web アプリケーションである。
エンジニアリング仕様書向けのクリーンな通常表示モードと、インフォグラフィック調の 4 スタイルを切り替えられる「Visual Stage」モードを備える。

初期プロトタイプの機能・デザイン仕様は [linea_functional_and_design_specification.md](linea_functional_and_design_specification.md) を参照する。

## 2. アクター

| アクター | 説明                                                                                 |
| :------- | :----------------------------------------------------------------------------------- |
| ユーザー | Markdown および Mermaid 記法で仕様書・設計書・インフォグラフィックを作成・閲覧する人 |

## 3. 機能要求 (FR)

増分開発（`swe1`）を進めるごとに本節へ追記する。初期プロトタイプ時点の主な機能は以下のとおり。

| ID     | 機能名                         | 概要                                                                                                                                    | 対応する初期仕様書                                                                                                    |
| :----- | :----------------------------- | :-------------------------------------------------------------------------------------------------------------------------------------- | :-------------------------------------------------------------------------------------------------------------------- |
| FR-001 | ビューモード切替               | `Split`（エディタ＋プレビュー）、`Canvas`（プレビューのみ）、`Code`（エディタのみ）の 3 モードを切り替える                              | [2.1 通常モード](linea_functional_and_design_specification.md#21-通常モードsplit--canvas--codeエンジニアリング仕様書) |
| FR-002 | 通常モード（仕様書表示）       | Markdown と Mermaid 図をフラットで高密度なエンジニアリング仕様書スタイルで描画する                                                      | [2.1 通常モード](linea_functional_and_design_specification.md#21-通常モードsplit--canvas--codeエンジニアリング仕様書) |
| FR-003 | Visual Stage モード            | 文書と Mermaid 図を 4 種のインフォグラフィックスタイル（Pastel Shapes / 2-Tier Cards / Vibrant Circles & Dots / Editorial Cream）で描画する | [2.2 Visual Stage](linea_functional_and_design_specification.md#22-visual-stageリファレンス完全準拠インフォグラフィックスタジオ) |
| FR-004 | テーマ・パレット・矢印形状切替 | Light / Dark 外観切替、4 種のカラーパレット（Cobalt / Emerald / Amber / Royal）、3 種の矢印形状（Smooth / Step / Straight）を切り替える | -                                                                                                                     |
| FR-005 | 図の個別操作・エクスポート     | 各ダイアグラムカードの拡大表示（Expand）、表示倍率切替（Fit / 1:1）、SVG・高解像度 PNG ダウンロード、HTML エクスポートを行う            | -                                                                                                                     |

## 4. 非機能要求 (NFR)

| ID      | 項目                   | 内容                                                                        |
| :------ | :--------------------- | :-------------------------------------------------------------------------- |
| NFR-001 | スタンドアロン動作     | バックエンド API を必要とせず、ブラウザのみで完結して動作する               |
| NFR-002 | キャッシュとエラー耐性 | FNV-1a ハッシュによる SVG キャッシュで再描画を高速化し、構文エラー時は直前の正常描画（LKG）を保持する |
| NFR-003 | セキュリティ           | Markdown から生成した HTML は DOMPurify でサニタイズしてから DOM に反映する |
