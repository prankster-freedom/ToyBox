# devenv（ローカル開発環境の起動・停止）

ローカルの開発環境（npm の開発サーバー）を起動・再起動・停止する。ユーザーが本スキルを呼び出したこと自体が実行の承認を兼ねるため、本スキルに【承認】の工程はない。本スキルの手順に限り、ユーザーの承認を待たずに `npm run` を実行してよい。

操作: $ARGUMENTS

起動に使う npm スクリプト（`dev` など）は、`package.json` の `scripts` で確認する。リポジトリ固有の起動方法がある場合は `AGENTS.repo.md` に従う。

## start（起動・再起動）

1. ローカルの npm 環境が起動済みの場合は、それを実行しているシェルも含めて停止する。
2. 停止したことを確認する。
3. ローカルの npm 環境を起動し、起動できたこと（URL やポートなど）を報告する。

## stop（停止）

1. ローカルの npm 環境が起動していれば、それを実行しているシェルも含めて終了する。
2. 終了したことを確認して報告する。起動していなかった場合は、その旨を報告する。
