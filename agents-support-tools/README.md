# agents-support-tools

AI エージェントがスキル（`.claude/skills/`）の手順を実行するときに使う補助スクリプトを置く。

- ツールごとにフォルダを分け、各フォルダに `README.md`（目的・使い方・呼び出し元のスキル）を置く
- スキルからは、リポジトリ直下からの相対パスで参照する
- 実行の出力や一時ファイルは `work/` に置き、ここには残さない

| フォルダ                          | 内容                                          | 呼び出し元 |
| :-------------------------------- | :-------------------------------------------- | :--------- |
| [md-table-align](md-table-align/) | Markdown の表の列の位置を等幅表示向けに揃える | doc        |
