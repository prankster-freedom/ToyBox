# Feature Requirement Specification: markdown-typography

本ドキュメントは、Luxyno における高速モードおよび Visualモードのドキュメントシート外観と、Markdown 各種記法のタイポグラフィ・描画に関する機能要求仕様を定義する。

対応する全体 SRS: [doc/1.SRS.md](../../1.SRS.md)

## 対象機能要求一覧

| ID     | 機能名                             | 概要                                                                   |
| :----- | :--------------------------------- | :--------------------------------------------------------------------- |
| FR-002 | 高速モード（ドキュメントシート）   | 純白またはディープスレートのフラットなドキュメントシートとして描画する |
| FR-003 | Visualモード（ドキュメントシート） | Editorial Cream のウォームクリームシートなど、各スタイルに応じた背景・余白・見出し構造で描画する |
| FR-009 | 同梱サンプルの Markdown 記法の描画 | `notation_sample.md` に記載された各種 Markdown 記法を、高速モード・Visualモードの両方で見分けられるように描画する |

---

## 機能要求の詳細

### FR-002 / FR-003: ドキュメントシート外観

- **高速モード**:
  - 純白（Light: `#FFFFFF`）またはディープスレート（Dark: `#0F172A`）のフラットなシート。
  - 自然で高密度な仕様書スタイルを維持し、長文の技術文書でも視認性を保つ。
- **Visualモード**:
  - `Editorial Cream` スタイルではウォームクリーム（`#F7F4EB`）の誌面調背景を適用。
  - 各スタイルに応じたセクションカード化、適切な余白（マージン・パディング）、洗練されたフォントファミリ・カーニングを適用する。

### FR-009: 同梱サンプルの Markdown 記法の描画

- Light / Dark のどちらの外観でも、以下の Markdown 記法がそれぞれ明確に見分けられること：
  1. **見出し（h1〜h6）**: 階層ごとにフォントサイズおよび太さが異なり、本文と一目で見分けられる。
  2. **箇条書き・番号付きリスト**: 箇条書きにはビュレット記号、番号付きリストには連番が付与され、ネスト（入れ子）は適切にインデントされる。
  3. **リンク**: 本文と異なるアクセント色で表示され、リンクであることが即座に認識できる。
  4. **インラインコード・コードブロック**: 本文と異なる背景色および等幅フォント（Monospace）でレンダリングされる。
  5. **引用（Blockquote）**: 左ボーダー線とインデントにより、本文と区別して表示される。
  6. **テーブル（表）**: Markdown で指定した列アライメント（左・中央・右寄せ）に従ってセル内容が整列される。Dark 外観でも境界線が視認可能であること。
  7. **水平線（hr）**: 背景と見分けられるソリッドラインで描画される。
  8. **HTML 標準要素**: `<details>` / `<summary>`, `<kbd>`, `<mark>`, `<sub>` / `<sup>` などの標準 HTML タグが、その要素固有の意図された外観で表示される。
- **背景・根拠**: 本アプリではリセット CSS や Tailwind CSS を読み込んでいるため、未定義の標準タグがプレーンテキスト化する問題を防ぐ。`notation_sample.md` には独自の装飾クラスを用いず標準 HTML 要素のみを使用し、純粋な Markdown/HTML 互換性を保証する。
