# Feature Requirement Specification: front-matter

本ドキュメントは、Lucivo における YAML フロントマターの解釈、本文との分離、シンタックスハイライト、および表示切替（ON/OFF）に関する機能要求仕様を定義する。

対応する全体 SRS: [doc/1.SRS.md](../../1.SRS.md)

## 対象機能要求一覧

| ID     | 機能名                    | 概要 |
| :----- | :------------------------ | :--- |
| FR-011 | YAML フロントマターの表示 | 文書先頭の YAML フロントマターを本文と分離し、ボタンで表示切替およびキー・値・コメントの色分け表示を行う |

---

## 機能要求の詳細

### FR-011: YAML フロントマターの表示

- **フロントマターの定義と検出**:
  - 文書の 1 行目が `---` だけの行で始まり、次の `---`（または `...`）だけの行までの領域をフロントマターとして認識する。
  - 文書途中に現れる `---` は通常の水平線（hr）として扱う。閉じのデリミタが存在しない場合はフロントマターとして扱わない。
- **表示切替（ON / OFF）**:
  - ヘッダーの「YAML」トグルボタンで表示の ON / OFF を切り替えられること。
  - 高速モード・Visualモードの双方で切り替え可能とし、表示モードやテーマを変更しても ON / OFF の状態を維持する。
  - 起動直後の初期状態は OFF とする。
- **レンダリング仕様**:
  - **OFF の場合**: フロントマターを完全に非表示とし、本文の先頭に不要な水平線や YAML テキストが現れないようにする。
  - **ON の場合**: 本文の直前に「Front Matter」と明記された専用のカード領域を配置し、行・インデントを正確に保った等幅フォントでレンダリングする。キー、文字列/数値/ブール値、コメントを視覚的に識別できるよう色分け（ハイライト）表示する。
- **フロントマターが存在しない文書の扱い**:
  - フロントマターのない文書では、「YAML」ボタンの状態に関わらず本文表示に影響を与えない。
- **背景・根拠**: 多くの技術文書や静的サイトジェネレータ（Jekyll, Hugo, Astro 等）の Markdown は先頭にメタデータとして YAML フロントマターを持つ。通常の Markdown パーサー（Marked）では先頭の `---` が水平線、中身が本文段落として解釈され可読性を著しく損なっていた。解析専用ライブラリを追加して表形式化する案は、起動軽快性（NFR-006）を損ね入れ子構造を表現しにくいため採用せず、高速な正規表現ベースの分離・シンタックスハイライトを採用した。
