# 採用ラフ: Visualモードの記述パターン別の雛形と動的ステージ演出

確定した寸法・色・動的振る舞いは [features/visual-templates.md](../../features/visual-templates.md) を正とする。本書は検討時の構図とインタラクションの記録である。視線の流れを矢印（→ ↓）で示す。

## RGH-001 リード型

```text
┌────────────────────────────────────────────┐
│ STAGE 01  概要                              │ ① 見出し
│ ──────────────────────────────────────────  │
│ ┃ 大きめ・太めの本文で、章の主張を         │ ② 縦線から文字へ（↓）
│ ┃ 2〜4 行で述べる。                         │
└────────────────────────────────────────────┘
```

- 主役: 本文そのもの。装飾は左の縦線だけにし、文字の大きさで主役を示す。

## RGH-002 要点カード型

```text
┌──────────────────────────────────────────────────────┐
│ STAGE 02  特長                                         │
│ 導入の一文（任意）                                     │
│ ┌▀▀▀▀▀▀▀▀┐  ┌▀▀▀▀▀▀▀▀┐  ┌▀▀▀▀▀▀▀▀┐  ┌▀▀▀▀▀▀▀▀┐       │ Z 型に流れる
│ │01    ◢ │→ │02    ◢ │→ │03    ◢ │→ │04    ◢ │       │ ◢ = AST-007 コーナー透かし
│ │題      │  │題      │  │題      │  │題      │       │
│ │説明    │  │説明    │  │説明    │  │説明    │       │
│ └────────┘  └────────┘  └────────┘  └────────┘       │
└──────────────────────────────────────────────────────┘
```

- 主役: 項目の数と題。番号と上端の帯の色で、項目を数えやすくする。列の数は項目の数で決める（2・3 個は 1 行、4 個は 2 × 2、5・6 個は 3 列）。

## RGH-003 手順型

```text
横並び（4 個以下・版面 40rem 以上）
  (1)━━ » ━━(2)━━ » ━━(3)━━ » ━━(4)   → 左から右へ（» = AST-008 方向シェブロン）
  受付      確認      発注      出荷

縦並び（5 個以上・版面 40rem 未満）
  (1) 受付                          ↓ 上から下へ
   ┃
  (2) 確認
```

- 主役: 順序。丸と線・方向シェブロンでつなぎ、要点カード型（並列）との違いを形で示す。

## RGH-004 ステートメント型

```text
┌────────────────────────────────────────────┐
│                   (( “ ))                   │ ① AST-006 彫刻引用符＋光輪で目を引く
│        構文に、光と舞台を。                  │ ② 一文（中央）
│            — 出典                           │ ③ 出典
└────────────────────────────────────────────┘
```

- 主役: 一文。余白を大きく取り、講演のスライドの 1 枚のように見せる。

## RGH-005 解説＋図版型

```text
┌──────────────────────────────────────────────────────┐
│ STAGE 09  フローチャート                               │
│ ┌ 本文（5）──────┐  ┌ 図版（7）───────────────────┐ │
│ │ 解説の段落      │→ │                              │ │ F 型: 左で読み、右で確かめる
│ │ ・箇条書き      │  │        Mermaid の図          │ │
│ └────────────────┘  └──────────────────────────────┘ │
└──────────────────────────────────────────────────────┘
```

- `FR-015` で実装済み。図が右の段に収まらない場合は 1 段組みになる。

## RGH-006 ベクター装飾素材の組み込み

```text
┌ ❖ [▬▬▬▬]  Luxyno サンプル文書 ──────────────┐  ❖ = AST-005 ヒーロー・プリズムエンブレム
└─────────────────────────────────────────────┘
```

- 主役を引き立てる細部の質感として、CSS の単調な線やシステムフォントの引用符に頼らず、専用設計した 4 種のベクター素材（`AST-005`〜`008`）を要所に配置する。
- ホバー時にプリズムが微細に回転し、カードの透かしファセットがスライドするなど、生きている展示パネルの質感を出す。

## RGH-007 要点カード・手順ステップのインタラクティブ・スポットライト

```text
【要点カードのクリック時】
  ┌────────┐  ┏━━━━━━━━┓  ┌────────┐
  │01 (減光)│  ┃02 注目!┃  │03 (減光)│   ← クリックしたカードが浮き上がり光彩を放つ
  └────────┘  ┗━━━━━━━━┛  └────────┘

【手順ステップ (3) のクリック時】
  (1)━━ » ━━(2)━━ » ━━((3))┈┈ » ┈┈(4)
  到達済み   到達済み   現在注目    未到達(減光)
```

- 講演者や展示説明員が、話しているカードや現在の工程をクリックすると、その要素にスポットライトが当たり、聴衆の視線を瞬時に集められる。再クリックまたは `Escape` で解除。

## RGH-008 STAGE バッジによるスラブ注目モード

```text
  ┌ STAGE 01 ──────────────────────┐ (減光 opacity: 0.42)
  ┏ [STAGE 02 ★] 注目中のスラブ ━━━┓ (強調リング＋浮き上がり)
  ┌ STAGE 03 ──────────────────────┐ (減光 opacity: 0.42)
```

- スラブ見出しの `STAGE nn` バッジをクリックすると、その章全体がステージの中央主役としてハイライトされ、前後の章が静かに一歩引く。

## RGH-009 ルミナス・フロー（手順トラックとダイアグラム結線上を光が流れる演出）

```text
【1. 手順型（.vs-steps）のルミナス・トラック】
   (1)━━ ✦» ━━(2)━━ ✦» ━━(3)━━ ✦» ━━(4)
        ~~~~~~~>      ~~~~~~~>      ~~~~~~~>  ← 接続線上を 4 色パレットの光脈が左→右（縦は上→下）へ流れる

【2. Visualモード ダイアグラム（フローチャート・状態遷移図・シーケンス図）のルミナス・ビーム】
   [ Node A ] ━━━ ✦ ━━━▶ [ Node B ] ━━━ ✦ ━━━▶ [ Node C ]
                 ~~~>                  ~~~>   ← 結線パス（.luxyno-flow-beam）上を光の粒子が矢印方向へ滑走
```

- 主役: フローの向きと生命感。「構文に、光と舞台を（Luxyno）」のコンセプトを視覚化し、静的な線ではなく情報の流れそのものが光として脈動するステージ演出。
- 無秩序に動く背景パーティクル（`RGH-903`、ボツ）とは異なり、線の上だけを進行方向に沿って滑らかに流れるため、本文の読解を邪魔せず視線を自然に上流から下流へ導く。
