# Luxyno 誌面雛形レンダリングサンプル

この文書は、Visualモードで各章（`h2`）の記述パターンに応じて自動適用される誌面の雛形（エディトリアルデザインテンプレート）を確認するためのサンプルです。

## 1. リード型（lead）の確認

章の本文要素が 1〜2 個の短い段落（合計 160 字以内）のみで構成される場合、自動的にリード型の雛形が適用されます。左端にスタイルに応じた 4 色グラデーションの縦線が配置され、大きめ・太めのフォントで主張を強調します。

これは 2 つ目の段落です。段落間の適切な余白とリズム感を保ちながら、セクションの概要やコンセプトを一目で伝えます。

## 2. 要点カード型（points）: 3 列カード

要点や選択肢、特長などの並列項目を整理する雛形です。箇条書きが 2〜6 項目で短い場合、番号付きカードのグリッドに変換されます。各項目の先頭が「**題**: 本文」の形式であれば、題が独立して強調表示されます。

- **軽快なレスポンス**: 高速モードは無駄な装飾を排し、ミリ秒単位で素早くプレビューします。
- **展示会品質の誌面**: Visualモードは大画面での講演や展示に耐えるトップデザイナーレベルの品格を提供します。
- **標準記法を維持**: 独自記法は一切不要。プレーンな Markdown をそのまま記述するだけで誌面化されます。

## 3. 要点カード型（points）: 4 列カード（2×2 または 1 行）

項目の数が 4 個の場合、画面幅に応じて 4 列（1 行）または 2×2 のグリッドに整列します。上端にはスタイルパレットの 4 色がアクセント帯として配されます。

- **パステル図形**: 柔らかく親しみやすいトーンでビジネス企画や教育資料に適したパレット。
- **2段カード**: 硬質で知的なコントラスト。仕様書やアーキテクチャ設計に最適なスタイル。
- **5色サークル**: 彩度の高いビビッドな配色。カンファレンスや製品発表で視線を集めます。
- **クリームチャート**: 落ち着いたクラシックモダン。論文やエッセイ、技術解説に調和します。

## 4. 手順型（steps）: 横並びフロー（4 項目以下）

順序に意味のある工程や時系列を視覚化する雛形です。番号付きリストが 2〜8 個で短い場合に適用されます。項目が 4 個以下かつ十分な幅がある場合は、接続線で結ばれた横並びフローになります。

1. Markdown を開く
2. Visualモードに切り替える
3. 好みのスタイルを選ぶ
4. 展示用画像や HTML を書き出す

## 5. 手順型（steps）: 縦並びフロー（5 項目以上）

項目が 5 個以上の場合や、幅が狭い環境（Split 表示時など）では、自動的に縦並びの手順フローへ切り替わります。

1. 要求分析とコンセプト策定
2. DTP デザイン仕様とラフの検討
3. エンジニアリング実装と機能テスト
4. ゲラ出力によるデザイン校正
5. 校了判定とコミット・リリース

## 6. ステートメント型（quote）の確認

理念やフィロソフィー、引用文を一文で印象づける雛形です。章が引用（`blockquote`）1 つ（240 字以内）で構成される場合、大きな引用符と共に中央揃えのバランスレイアウトになります。末尾のダッシュ行は出典として扱われます。

> 構文に、光と舞台を。ロジックの構造美をそのままスポットライトの当たるステージへと引き上げる。
>
> — Luxyno のコア・フィロソフィー

## 7. 解説＋図版型（split）の確認

本文要素と図がちょうど 1 つずつ存在する章は、本文（左 5 カラム）と図版（右 7 カラム）の 2 段組みレイアウトで自動配置されます。

システムの入力からレンダリング、出力までの流れです。テキスト入力は即座に解析され、キャッシュを活用してミリ秒単位で画面へ反映されます。右の図が横幅に収まる限り、解説文と並列してスマートに閲覧できます。

```mermaid
flowchart LR
    A[Markdown] --> B[Parser]
    B --> C[Renderer]
    C --> D[Display]
```

## 8. 標準型（standard）: 複合要素を含む章の確認

小見出し（`h3`）、コードブロック、表、数式などの複合要素を含む章や、上限文字数を超える長い章は、雛形判定をパスして標準型のスラブとして端正に組版されます。

### 小見出しのある構成

複合的な解説文書では、標準型の安定したレイアウトが可読性を担保します。

| 項目       | 高速モード             | Visualモード                   |
| :--------- | :--------------------- | :----------------------------- |
| 最優先事項 | 軽快性（ミリ秒の反応） | 見た目の品格（展示品質）       |
| 組版方式   | 仕様書向け高速組版     | 雛形判定付きエディトリアル組版 |

```bash
# ビューアーの起動
npm run dev
```

### ベクター装飾素材と動的ステージ演出の確認

Visualモードでは、以下のベクター装飾素材（`assets/motifs/`）とインタラクティブなスポットライト演出を確認できます。

- **ベクター装飾素材**: ヒーロー上部のプリズム・エンブレム、要点カード右上のコーナーオーナメント、手順ステップ間の進行シェブロン、ステートメント上部の引用符モニュメントが、選択中のスタイル（4 色パレット）に連動して描画されます。
- **インタラクティブ・スポットライト**: 要点カード（第 2・3 章）をクリックするとそのカードが強調され、手順ステップ（第 4・5 章）をクリックすると先頭からその工程までがハイライトされます。また、各章の `STAGE` バッジをクリックするとその章にフォーカスが当たります（再クリックまたは `Escape` キーで解除）。
