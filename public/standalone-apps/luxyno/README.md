# Luxyno — Exhibition-Grade Markdown Viewer

- **Version**: `0.1.0`（`1.0.0` に上げるまでは、互換性のない変更も MINOR で上げる。`AGENTS.repo.md` 5 章）

Markdown 文書と Mermaid ダイアグラムを、エンジニアリング仕様書スタイルの「高速モード」と 4 種のインフォグラフィックスタイルの「Visualモード」で表示する、スタンドアロンの Markdown ビューアーです。左ペインのエディタで書き換えると、プレビューにすぐ反映されます（エディタは当面は付随的な機能です）。

**差別化のポイント**
- 既存の Markdown / Mermaid ビューアーより軽快に動作すること。
- モード切替により対象ドキュメントの表示をトップデザイナーレベルのデザインに変換できること。

**2 つのモードの位置づけ**
- **高速モード**: 起動から閲覧の操作まで、軽快に動作することを最優先にしています。
- **Visualモード**: 講演資料や展示素材としてそのまま表示できる、トップデザイナーが制作したような品質を目指しています。

詳しくは [要求仕様書の「プロダクトコンセプト」](doc/SRS.md#11-プロダクトコンセプト) を参照してください。

## 使い方

### 最も簡単な使い方

1. ブラウザで [index.html](index.html) を直接開くか、ToyBox の開発サーバー起動中に `http://localhost:3000/standalone-apps/luxyno/` へアクセスします。
2. ヘッダーの「ファイル」メニュー →「Markdown を開く…」で Markdown ファイル（`.md` / `.markdown` / `.txt`、UTF-8）を読み込みます。起動直後のエディタは空です。
3. 左ペイン（`SOURCE MARKDOWN`）で Markdown と ```` ```mermaid ```` コードブロックを編集すると、右ペインにリアルタイムでプレビューが表示されます。

Markdown と Mermaid の記法の例は、同梱の [sample.md](sample.md) にあります。「Markdown を開く…」で開いてください。

### 主な使い方のパターン

- **ファイルの読み込み**: 「ファイル」メニュー →「Markdown を開く…」で読み込みます。読み込んだ直後のエディタは読み取り専用です。編集するときは、エディタ上部の「編集」を押してください。保存していない編集内容がある状態で別のファイルを読み込むと、確認ダイアログが表示されます。
- **保存**: ヘッダーの「保存」で、エディタの内容を Markdown ファイルとしてダウンロードします（元のファイルは上書きしません）。
- **表示モードの切り替え**: ヘッダー中央の `Split`（左右分割）/ `Canvas`（プレビューのみ）/ `Code`（エディタのみ）で作業画面を切り替えます。
- **描画モードの切り替え（高速モード / Visualモード）**: ヘッダー中央の「高速モード」「Visualモード」ボタンで、軽快な仕様書表示とインフォグラフィック表示を切り替えます。Visualモード時や上部のスタイルバー（`🎨 パステル図形` / `📋 2段カード` / `⭕ 5色サークル` / `📖 クリームチャート`）をクリックすると、Mermaid ダイアグラムと文書がインフォグラフィック調に変換されます。本文と 1 つの図を持つ章（`h2`）は、図が右カラムに収まる場合は左に本文・右に図の 2 段組みで表示されます（横長の大きな図は自動で全幅の 1 段組みになります）。
- **章の内容に合わせた誌面（Visualモード）**: 章（`h2`）の書き方に応じて、誌面の雛形が自動で切り替わります。短い段落だけの章は大きな文字のリード、短い箇条書きは番号付きのカード、短い番号付きリストは手順の図、短い引用は中央揃えのステートメントになります。それ以外の章は通常の組版です。独自の記法は不要で、雛形の色は選んでいるスタイルに合わせて変わります。条件の詳細は [デザイン仕様](doc/DTP/features/visual-templates.md) を参照してください。
- **テーマの変更**: 右上の太陽/月アイコンで Light / Dark を切り替え、パレット設定ボタンからカラーパレット（Cobalt / Emerald / Amber / Royal）を変更できます。
- **矢印の形状**: フローチャートのカードのヘッダーで、図ごとに矢印の形状（曲線 / 直角 / 直線）を選べます。既定は直角です。選んだ形状は画面の表示の間だけ保たれ、文書には書き込まれません。
- **図のエクスポート**: 各ダイアグラムカードの右上から、表示倍率切替（`Fit` / `1:1`）、`PNG`（高解像度）・`SVG` ダウンロード、`Expand`（拡大モーダル表示）を行えます。`Fit` は図を枠の幅に合わせますが、文字が小さくなりすぎる大きな図は、それ以上縮小せず横スクロールで表示します。
- **YAML フロントマター**: 文書の先頭の `---` で囲んだ YAML は、本文とは分けて扱います。ヘッダーの `YAML` ボタンで表示を切り替えられます（起動直後は非表示、高速モード・Visualモードの両方で有効）。
- **数式**: 本文に `$…$`（インライン）や `$$…$$`（ブロック）で TeX の数式を書けます（KaTeX で描画）。フローチャートとシーケンス図では、ラベルに `$$…$$` で数式を書けます。

## 動作確認

ToyBox のリポジトリ直下に Playwright（Chromium）を導入済みであれば、次のコマンドでテスト仕様（[doc/5.test_spec/](doc/5.test_spec/)）の自動確認を実行できます。図の画像は `work/test/` に保存されます（git 管理外）。CDN からライブラリを読み込むため、インターネット接続が必要です。

```bash
node public/standalone-apps/luxyno/tests/e2e.cjs
```

- 所要時間は 3〜5 分です。合否は標準出力と `work/test/results.json` に出力されます。
- 「確認方法」が目視の TC は、`work/test/shots/` の画像（モード × 図の数と、雛形のある章、約 230 枚）で確認します。
- 再実行すると `work/test/` は上書きされます。前回の出力を残す場合は、実行前に別のフォルダへ移してください。

### 変更するときの注意（過去にはまった点）

詳細は各設計 ID の「背景」を参照してください。

- **同じ id の重複**: 高速モードと Visualモードの両方に図を残すと、描画先と SVG 内の参照（矢じり・グラデーション）が非表示側に向きます。表示しない側は空にし、SVG 内の id は図ごとに一意にしています（`DD-DIAG-001`〜`003`, `DD-DIAG-010`）。
- **Tailwind のリセット**: Tailwind CSS がブラウザ標準のスタイルを消すため、Markdown の要素の見た目はすべて `style.css` で定義しています（`DD-MD-001`〜）。
- **Tailwind のクラスの追加**: Tailwind は使っているクラスだけを事前に生成した `css/tailwind.css` を読み込んでいます。`index.html` や `app.js` で新しい Tailwind のクラスを使ったら、`node public/standalone-apps/luxyno/tools/build-tailwind-css.cjs` で作り直してください。作り直さないと、そのクラスは効きません。
- **遅延読み込み**: Mermaid と KaTeX は、図・数式が文書に現れるまで読み込みません。`window.mermaid` / `window.katex` がない状態でも動くように書いてください（`loadLibrary()`）。
- **Visualモードの装飾の範囲**: 図形の装飾は、フローチャート・状態遷移図・シーケンス図だけに適用します。他の図種に適用すると崩れます（`DD-DIAG-011`）。
- **Dark の Visualモード**: カード背景は外観に合わせて暗くなりますが、装飾したノードの塗り（色付きの図形・白いカード）は明るいままです。背景の上に直接描く線・文字は明るく、ノードの上の文字は暗く、それぞれ色を明示します（ページの文字色を継承させない。`DD-DIAG-024`, `DD-DIAG-031`）。
- **Mermaid 10.9.1 の癖**:
  - シーケンス図のライフラインの class は `"200"` になります（`DD-DIAG-020`）。
  - タイムラインは、1 つの図の中で同じ id を出力します（`DD-DIAG-010`）。
  - 状態遷移図の `<<choice>>` などは、遷移で使う前に宣言する必要があります。
- **表示枠の中央寄せ**: `justify-content: center` のままだと、表示枠より広い図の左側がスクロールで見えなくなります（`DD-DIAG-032`）。
- **数式**: 数式の置き場所はサニタイズの後に KaTeX で描画します。KaTeX の出力をサニタイズにかけると崩れるためです（`DD-MATH-012`, `DD-MATH-020`）。
- **サンプルとテスト**: `sample.md` の図の並び（1 つ目がフローチャート、など）と、章の雛形（冒頭はリード、2 章・26 章は要点カード、など）を前提にしたテストがあります。図や章を追加・削除したら、`tests/e2e.cjs` とテスト仕様の対応する TC も見直してください。
- **Visualモードの雛形**: 雛形の寸法・色・判定の条件は、デザイン仕様（`doc/DTP/features/visual-templates.md`）を正とします。変えるときは、先にデザイン仕様を直してから `style.css`・`app.js`（`TEMPLATE_LIMITS`）を合わせてください（`DD-VTPL-001`）。

## 既知の課題

テストで見つかった、不合格ではないが改善の余地がある点と、プロダクトコンセプトに照らして見直しが必要な点です。対応するときは、`doc/SRS.md` への要求の追加から始めてください。

### コンセプトに照らして見直しが必要な点

- 判定基準: 軽快さ（`NFR-006`）と表示品質（`NFR-007`）の判定基準が未確定（[Issue #16](https://github.com/prankster-freedom/ToyBox/issues/16)）。
- 発表用の表示: 講演・展示の大画面で使うための全画面・発表用の表示がない（[Issue #20](https://github.com/prankster-freedom/ToyBox/issues/20)）。
- ブランド: ロゴ・シンボルマーク・ブランドカラーが画面に反映されていない（[Issue #22](https://github.com/prankster-freedom/ToyBox/issues/22)）。
- 高速モードの入力（`NFR-006`）: 入力のたびに文書全体の HTML を作り直している。Fit の計算と数式の描画はキャッシュしたが（Issue #19）、変更のあったブロックだけを差し替える差分更新は未対応。
- Visualモードの品質（`NFR-007`）: 文字の判読性（`NFR-005`）のため、大きな図は展示用のカードの中で横スクロールになる。スクロールバーは操作するときだけ目立つようにしたが（Issue #21）、横スクロール自体は残る。

### その他

- Mermaid の図のラベルに書いた `<img src="…">` は、`securityLevel: strict` でもイベント属性を除いて残り、画像を読み込む（スクリプトは実行されない。Issue #23）。
- Dark の高速モードで、マインドマップとタイムラインのノードの塗りが黒に近い（Mermaid が派生色を使うため）。白文字で判読はできる。
- 大きなフローチャートで、Mermaid の自動配置により、矢印がサブグラフの見出しの上を通ることがある（アプリ側では調整していない）。
- Visualモードの要点カード（`DTP-VTPL-030`）の中のインラインコードは、カードの幅によってはコードの枠ごと 2 行に折り返す（判読はでき、カードからはみ出さない）。折り返さない指定にすると長いコードがはみ出すため、保留している。
