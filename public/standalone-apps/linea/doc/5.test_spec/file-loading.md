# テスト仕様: ファイルの読み込みと初期表示（file-loading）

すべての TC は、`index.html` を `file://` で開いて実施する。確認方法が「自動」の TC は [tests/e2e.cjs](../../tests/e2e.cjs) で確認する。

| ID          | 観点                     | 手順                                                                             | 期待結果                                                                     | 確認方法 | 対応 ID                          |
| :---------- | :----------------------- | :------------------------------------------------------------------------------- | :--------------------------------------------------------------------------- | :------- | :------------------------------- |
| TC-FILE-001 | 起動直後の初期表示       | アプリを開く                                                                     | エディタが空で、プレビューに「ファイル」メニューから開くよう案内が表示される | 自動     | FR-007, DD-FILE-004, DD-FILE-020 |
| TC-FILE-002 | メニューの開閉           | 「ファイル」を押す → メニューの外側を押す → 再び「ファイル」を押す → Esc キーを押す | 押すとメニューが開き `aria-expanded` が `true` になる。外側のクリックと Esc キーで閉じる | 自動 | FR-006, DD-FILE-001, DD-FILE-002 |
| TC-FILE-003 | 未編集の状態での読み込み | 起動直後に `sample.md` を選ぶ                                                    | 確認ダイアログが出ない。エディタの内容がファイルと一致し、プレビューに見出しと図が表示され、トーストが出る | 自動 | FR-006, DD-FILE-010 |
| TC-FILE-004 | 編集後の読み込み（取消） | 読み込み後にエディタを編集し、再びファイルを選び、確認ダイアログでキャンセルする | 確認ダイアログが表示される。キャンセル後もエディタの内容は編集した内容のまま | 自動     | FR-006, DD-FILE-010              |
| TC-FILE-005 | 編集後の読み込み（置換） | TC-FILE-004 の後、再びファイルを選び、確認ダイアログで OK を押す                 | エディタの内容がファイルの内容に置き換わる                                   | 自動     | FR-006, DD-FILE-010              |
| TC-FILE-006 | 同じファイルの再選択     | ファイルを読み込んだ後のファイル選択の値を確認する                               | ファイル選択の値が空に戻っている（同じファイルを続けて選んでも読み込める）   | 自動     | DD-FILE-010                      |
| TC-FILE-007 | `file://` での動作       | TC-FILE-001〜006 を `file://` で開いた状態で実施する                             | すべて期待どおりに動作し、コンソールにエラーが出ない                         | 自動     | FR-006                           |
| TC-FILE-008 | 埋め込みサンプルの削除   | `js/app.js` を確認する                                                           | サンプル文書が埋め込まれていない                                             | 自動     | FR-007                           |
| TC-FILE-009 | 実ブラウザでのファイル選択 | 実際のブラウザで「Markdown を開く…」を選び、OS のファイル選択ダイアログで `sample.md` を選ぶ。同じファイルをもう一度選ぶ | ファイル選択ダイアログが開き、選んだファイルが読み込まれる。同じファイルを続けて選んでも読み込まれる | 手動 | FR-006, DD-FILE-003, DD-FILE-010 |

- TC-FILE-004〜006 の自動確認は、Playwright でファイル選択の値を直接設定する。OS のファイル選択ダイアログは自動確認できないため、TC-FILE-009 で手動確認する。
