# テスト仕様: Visualモードの記述パターン別の雛形（visual-templates）

`index.html` を `file://` で開き、`notation_sample.md` を読み込んでから実施する（TC-VTPL-002 は、判定の境界を確かめる文書をエディタに入れて実施する）。確認方法が「自動」の TC は [tests/e2e.cjs](../../tests/e2e.cjs) で確認する。画面の幅は 1300px とする（TC-VTPL-004・005 の狭い版面の確認を除く）。

「雛形のある章」は、`notation_sample.md` の冒頭（最初の `h2` より前）・2 章・26 章・27 章・28 章とする。コントラスト比は WCAG 2.x の相対輝度の式で求める。
