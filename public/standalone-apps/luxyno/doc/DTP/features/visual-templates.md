# デザイン仕様: Visualモードの記述パターン別の雛形（visual-templates）

Visualモードでは、文書を章（`h2`）ごとのスラブに分ける。本仕様は、スラブの中身の記述パターンを判定し、パターンに合った誌面の雛形で割り付けるデザインを定める。全体の版面・配色・書体は [DTP 全体設計書](../README.md)（`DTP-001`〜`004`）に従う。

- 対応する要求: `FR-016`（[visual-templates.md](../../SRS/features/visual-templates.md)）、`FR-015`（解説＋図版型）
- 採用したラフ: `RGH-001`〜`RGH-005`（[roughs/README.md](../roughs/README.md)）
- 使用する素材: `AST-001`〜`AST-004`（フォント。[assets/README.md](../assets/README.md)）。画像素材は使わない

## DTP-VTPL-001 雛形の判定

スラブの「本文要素」（見出し `h2` とフロントマターを除く、スラブ直下の要素）を調べ、上から順に最初に当てはまる雛形を適用する。

| 順位 | 雛形                                | 記述パターン（条件をすべて満たす）                                                                                         |
| :--- | :---------------------------------- | :------------------------------------------------------------------------------------------------------------------------- |
| 1    | 解説＋図版型（`split`）             | 図がちょうど 1 つあり、本文要素が 1 つ以上ある（`FR-015`）                                                                 |
| 2    | 標準型（`standard`）                | 図が 1 つ以上ある（1 位に当てはまらないもの）、または本文要素がない                                                        |
| 3    | リード型（`lead`）                  | 本文要素が段落（`p`）だけで 1〜2 個、文字数の合計が 1〜160 字                                                              |
| 4    | 要点カード型（`points`）            | 本文要素が「箇条書き（`ul`）1 つ」または「段落 1 つ＋箇条書き 1 つ」。項目が 2〜6 個で、どの項目も入れ子のリスト・コード・表・引用・チェックボックスを含まず 100 字以内 |
| 5    | 手順型（`steps`）                   | 本文要素が「番号付きリスト（`ol`）1 つ」または「段落 1 つ＋番号付きリスト 1 つ」。項目が 2〜8 個で、項目の条件は 4 位と同じ |
| 6    | ステートメント型（`quote`）         | 本文要素が引用（`blockquote`）1 つだけで、その中身が段落 1〜3 個、合計 240 字以内                                          |
| 7    | 標準型（`standard`）                | 上記のいずれにも当てはまらない                                                                                             |

- 文字数は、要素の文字（`textContent`）の前後の空白を除いた長さで数える。
- 背景: 雛形は「一目で主役が分かる」量の内容にだけ使う。上限を超える長い段落・項目の多いリストを大きな文字やカードにすると、展示パネルとして読み切れない量になり、かえって品質が下がるため、標準型に戻す。
- 背景（小見出しを含む章）: `h3` などの小見出し、表、コード、ブロック数式を含む章は、構成が複合しているため標準型とする。

## DTP-VTPL-010 標準型（standard）

- これまでのスラブの組版（`FR-003` / `FR-009`）のまま。見出しの下に本文要素を上から順に流す。
- 雛形を適用しない章の受け皿であり、すべての Markdown 記法を見分けられる組版を保つ（`FR-009`）。

## DTP-VTPL-020 リード型（lead）

用途: 章の主張・概要を述べる短い文章（文書の冒頭の導入文など）。

```text
┌ STAGE 01  概要 ───────────────────────────────┐
│ ┃ Luxyno は、Markdown を展示品質の誌面に         │
│ ┃ 変換するビューアーです。                       │ ← 大きめ・太めの本文
└────────────────────────────────────────────────┘
  ┃ = 4 色のグラデーションの縦線（--vs-c1 → --vs-c4）
```

- 段落を 1 つのリードの枠（`.vs-lead`）にまとめ、左に幅 4px・角丸 2px の縦線（4 色のグラデーション）を引く。縦線と文字の間は `1.25rem`。
- 文字は `DTP-004` のリード（`clamp(1.1rem, 1.8vw, 1.35rem)`・600・行送り 1.85）、色は主文字色（`--text-primary`）。
- 2 つ目の段落との間は `0.75rem`。

## DTP-VTPL-030 要点カード型（points）

用途: 特長・要点・選択肢などの並列の項目。

```text
┌ STAGE 02  特長 ─────────────────────────────────────────┐
│ （導入の段落があれば、ここに通常の本文で置く）            │
│ ┌▀▀▀▀▀▀▀▀▀▀▀┐ ┌▀▀▀▀▀▀▀▀▀▀▀┐ ┌▀▀▀▀▀▀▀▀▀▀▀┐            │
│ │ 01         │ │ 02         │ │ 03         │  ▀ = 上端 4px の帯 │
│ │ 軽快       │ │ 展示品質   │ │ 記法そのまま│  ← 項目の題（任意）│
│ │ 説明文…    │ │ 説明文…    │ │ 説明文…    │            │
│ └────────────┘ └────────────┘ └────────────┘            │
└──────────────────────────────────────────────────────────┘
```

- 箇条書きをカードのグリッドにする。間隔は `1rem`。列の数は項目の数から決め、最後の行に 1 枚だけ残る端数を作らない。

  | 項目の数 | 列の数                              |
  | :------- | :---------------------------------- |
  | 2・3     | 項目の数と同じ（1 行）              |
  | 4        | 2（2 × 2）。版面 56rem 以上では 4（1 行） |
  | 5・6     | 3                                   |

  版面 30rem 以下では 1 列にする。
- カード: 角丸 16px、内側の余白 `1.25rem`、背景は本文より一段明るい（Light `#F8FAFC` / Dark `rgba(15, 23, 42, 0.45)`）、枠線 1px、影 `0 6px 18px -8px rgba(15, 23, 42, 0.12)`。
- 上端に幅 4px の帯を付ける。帯の色は項目の順に `--vs-c1`→`--vs-c2`→`--vs-c3`→`--vs-c4` を繰り返す。
- カードの先頭に 2 桁の番号（`01`, `02`…）を置く。`DTP-004` のカードの番号（1.75rem・800）、色は帯の色を濃く（Dark では明るく）した色（`DTP-003`）。
- 項目が「**題**: 説明」（太字の直後に `:` または `：`）で始まる場合は、太字を項目の題（1rem・700・主文字色）として番号の下に独立した行で置き、区切りの `:` は表示しない。
- 導入の段落がある場合は、カードの上に標準型の本文として置く。

## DTP-VTPL-040 手順型（steps）

用途: 手順・工程・時系列など、順序に意味のある項目。

```text
項目が 4 個以下で、版面の幅が 40rem 以上の場合（横並び）
   (1)━━━━━━━━(2)━━━━━━━━(3)━━━━━━━━(4)
  受け付ける   確認する    発注する    出荷する

項目が 5 個以上、または版面の幅が 40rem 未満の場合（縦並び）
   (1) 受け付ける
    ┃
   (2) 確認する
    ┃
   (3) …
```

- 番号付きリストを、番号の丸と接続線でつないだ手順図にする。
- 番号の丸: 直径 `2.5rem`、塗りは項目の順に `--vs-c1`〜`--vs-c4`、文字は濃紺（`#1E293B`、1.05rem・800）。丸の周りにスラブの背景色の輪（5px）を付け、接続線から浮かせる。
- 接続線: 太さ 2px、色は強い線の色（Light は `--border-strong`、Dark は `#64748B`）。丸の中心を結ぶ。
- 横並び: 項目を等幅の列に置き、丸の下に中央揃えで文字を置く。版面の幅（スラブの幅）で判定するため、`Split` 表示の狭いプレビューでも詰まらない。
- 縦並び: 丸を左に、文字を丸の右（左端から `3.5rem`）に左揃えで置き、項目の間隔は `0.9rem`。
- 導入の段落は、要点カード型と同じく手順の上に置く。

## DTP-VTPL-050 ステートメント型（quote）

用途: 理念・標語・引用など、その一文を見せたい章。

```text
┌ STAGE 03  フィロソフィー ──────────────────────────┐
│                        “                            │ ← 大きな引用符（--vs-c1）
│              構文に、光と舞台を。                    │ ← 中央揃えの大きな文字
│                — Luxyno のフィロソフィー             │ ← 出典（小さく、薄く）
└─────────────────────────────────────────────────────┘
```

- 引用の左線と左の余白を外し、最大幅 `46rem` で中央に置く。文字は `DTP-004` のステートメント（中央揃え、`text-wrap: balance`）。
- 上に大きな引用符（`“`、4.5rem・800、`--vs-c1`）を置く。
- 最後の段落が `—`（全角ダッシュ）・`―`（水平線）・`--` で始まる場合は、出典として 0.875rem・600・薄い文字色（Light は `--text-muted`、Dark は `#94A3B8`）で置く。

## DTP-VTPL-060 解説＋図版型（split）

- `FR-015` の自動 2 段組み（本文 5 : 図版 7）。図が右の段に収まらない場合と、版面幅 768px 未満は 1 段組みになる。デザインは変えず、雛形の 1 つとして台帳に登録する（`RGH-005`）。

## DTP-VTPL-070 スタイル別の配色の適用

- 雛形のアクセント色、章番号のバッジ（`STAGE nn`）の塗り、ヒーローの 4 色バーは、選んでいるインフォグラフィックスタイルの 4 色（`DTP-003`）を使う。
- スタイルを切り替えると、図と同時に誌面のアクセント色も切り替わる。

## DTP-VTPL-080 Dark の外観

- カードの背景・枠線、手順の丸の輪の色は、Dark のスラブの背景（`#1E293B`）に合わせる。アクセント色そのもの（帯・丸の塗り・引用符）は Light と同じ色を使う。
- 文字の色は、主文字色・薄い文字色のトークン（`--text-primary` / `--text-muted`）に従う。ただし、Dark の `--border-strong`・`--text-muted` はスラブの背景に近いため、手順の接続線と引用の出典は明るい色にする（`DTP-VTPL-040`, `050`）。
