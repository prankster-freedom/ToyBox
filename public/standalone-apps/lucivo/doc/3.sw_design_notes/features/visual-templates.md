- **背景（DD-VTPL-001）**: 判定はタグ名と `textContent` の長さだけで行う。`getComputedStyle` や要素の大きさの計測を使わないため、Visualモードの描画のたびに判定しても軽く、キャッシュからの再描画で `getComputedStyle` を呼ばない条件（`TC-PERF-002`）を保つ。
- **背景（DD-VTPL-002）**: 組み替えは、`buildVisualStageHtml()` がスラブごとに作る DOM（`wrapper`）の上で行う。この DOM は DOMPurify でサニタイズした後の HTML から作っているため、組み替えで付ける `class`・`style`（CSS 変数）がサニタイズで消えることはない。
- **背景（DD-VTPL-011）**: 列の数を CSS の自動段数（`auto-fit`）で決めると、版面の幅によって 3 個が 2 列＋1 枚になるなど、最後の行に端数が出た（`RGH-902`）。項目の数から列の数を決めることで、端数の行を作らない。
- **背景（DD-VTPL-014, 015）**: 装飾要素（`aria-hidden="true"` の空 `span`）はテキストノードを持たず、`strong`・`em`・`code`・`a`・`del` でもないため、高速モードとの内容一致検証（`TC-VTPL-003`）に影響しない。スポットライトの切り替えは `#visual-stage-container` へのイベント委譲で行うため、再描画のたびに個別要素へリスナーを貼り直す必要がなく、`renderApp()` も呼ばないためミリ秒単位で応答する。

| ID          | 項目                 | 設計                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     | 対応する要求・デザイン   |     |

| DD-VTPL-040 | 表紙の値の読み取り   | `renderApp()` は `buildVisualStageHtml(cleanHtml, yaml)` にフロントマターの原文を渡す。`readCoverMeta(yaml)` は、先頭の列から始まる `title:`・`description:`・`tags:` の行だけを読む。値は引用符を外し、行末の `#` 以降をコメントとして除く。値が空、または `>`・`\                                                                                                                                                                                                                                                                                                      | ` のときは、続く字下げの行を空白でつないで値にする。`tags` は `[a, "b"]`・`a, b`・字下げした `- a` の 3 通りを読み、先頭の 4 個（`COVER_LIMITS.tags`）にする。題名は `h1` → `title` → ファイル名の順に決める | `FR-020`, `DTP-VTPL-100` |
| DD-VTPL-041 | 表の列の判定         | `buildVisualStageHtml()` は、スラブに分ける前の DOM のすべての `table` に `markTableColumns()` を適用する。列ごとに、本文のセルの文字（前後の空白を除く）から欠損の印（`EMPTY_CELL`: 空・`-`・`–`・`—`・`―`・`N/A`）を除き、残りがすべて `NUMERIC_CELL`（符号・通貨記号・桁区切り・小数と、`%`・英字 3 文字以内・`件`・`字` などの単位）に当てはまれば、見出しとセルに `.vs-num` を付ける。先頭の列と、`align` 属性を持つセルがある列は対象外とする。数値の列でなく、残りがすべて `TABLE_LABEL_CHARS`（10）字以内で空白を含まない列は、本文のセルに `.vs-label` を付ける | `FR-021`, `DTP-VTPL-110` |     |
| DD-VTPL-042 | 目次の組み立てと移動 | 章の番号は `STAGE nn` と同じ `sectionCounter` を使い、`h2` のあるスラブに `data-stage-no="nn"` を付ける。章が `COVER_LIMITS.agenda`（3〜15）個のとき、`buildCoverHtml()` が `ol.vs-cover-agenda` に章ごとの `button.vs-cover-agenda-item[data-stage-target="nn"]` を置く。列の数は 6 個以下で 2、それ以外は 3 とし、行の数 `--vs-rows` を `style` に書く。`setupVisualStageInteractions()` のクリックの委譲で、目次の項目を押すと対応するスラブを `scrollIntoView({ block: 'start' })` する（`prefers-reduced-motion: reduce` では `behavior: 'auto'`）                  | `FR-020`, `DTP-VTPL-100` |     |

- **背景（DD-VTPL-040）**: フロントマターの表示を OFF にしているときは `buildFrontMatterHtml()` の出力が本文に入らないため、表紙の値は HTML ではなく YAML の原文から読む。読み取った値は `escapeHtml()` を通してから表紙に入れる（`NFR-003`）。
- **背景（DD-VTPL-041）**: 列の判定はスラブに分ける前に行う。スラブの組み立てでは要素を複製するため、先に付けたクラスがそのまま残る。数値の判定で `align` 属性のある列を除くのは、`.vs-num` の `text-align: right` が Marked の出力する揃え（`TC-MD-006`）を上書きしないため。
- **背景（DD-VTPL-044）**: `overflow-wrap: anywhere` は、セルの最小幅の計算で文節の中の折り返しも数えるため、長い複合語が列の最小幅にならない。`word-break: auto-phrase` は実際の折り返しの位置に効くため、列の幅に余裕があれば文節の区切りで折り返す（`RGH-907`）。
