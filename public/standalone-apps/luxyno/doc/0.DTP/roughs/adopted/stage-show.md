# 採用ラフ: Visualモードの舞台演出（stage-show）

## RGH-010 シグナル・ライト（図の構造に沿って伝わる光）

```text
  背面の層: 光輪・ノードの逆光        前面の層: 白熱の芯・頭

  ╭──────╮                          時刻 0.2s  (A) が点灯
  │  A   │ ░░                       時刻 0.5s  A→B を光が進む
  ╰──┬───╯                          時刻 0.9s  (B) に届く → 逆光で輪郭が浮かぶ
     ┆ ·:=≡●   ← 尾は細く薄く、頭は白熱   時刻 0.9s  分岐は同時に分かれる
  ╭──▼───╮
  │  B   │
  ╰──────╯
```

- 主役: 図の意味（どこから、どこへ）。光を線の飾りから、意味を運ぶ信号へ変える。
- 視線誘導: 聴衆の視線が図の根から下流へ自然に運ばれる。発表者が図の順に説明する流れと揃う。
- `RGH-009` の置き換え。

## RGH-011 手順の彗星と到達の反応

```text
   (1)────────·:=≡●(2)────────────(3)────────────(4)
                    ↑ 丸の下をくぐる。届いた瞬間に丸の輪が光って広がる
```

- 図と同じ光の言語を、手順にも使う。誌面全体で光の見え方を統一する。

## RGH-012 ステージ発表（1 章 1 シーンの全画面）

```text
┌───────────────────────────────────────────────┐
│                  （上からの照明）               │
│                                               │
│  [STAGE 03] 章の見出し                         │
│                                               │
│  ┌ 01 ────┐  ┌ 02 ────┐  ┌ 03 ─ ─ ┐            │
│  │  見せた │  │ 話し中 │  ┆ まだ   ┆ ← 1 項目ずつ │
│  └────────┘  └━━━━━━━━┘  └ ─ ─ ─ ─┘            │
│                                               │
│ 章の題                         05 / 15 [操作]  │
│━━━━━━━━━━━━━━━━━━●─────────────────────────────│ ← 進行の光の線
└───────────────────────────────────────────────┘
```

- 主役: 章の中身。枠を外して舞台に直接置き、「ビューアーの画面」ではなく「発表の舞台」に見せる（Issue #20）。
- 暗転の舞台は、シグナル・ライトが本物の光として最も映える場所でもある。
- `RGH-105`（自動進行）は、この表示の `A` キーとして統合した。
