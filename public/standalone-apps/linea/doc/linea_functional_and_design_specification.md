# Linea 機能・デザイン仕様書

## 2. 表示モード・デザイン仕様

### 2.1 通常モード（Split / Canvas / Code）：エンジニアリング仕様書

- **背景・コンテナ:** 純白（Light: `#FFFFFF`）またはディープスレート（Dark: `#0F172A`）のフラットなドキュメントシート。
- **箱（ノード）:** 単一カラーのクリーンな 1.75px 枠線とフラット塗り。以前から動作していた自然で高密度な仕様書スタイルを 100% 維持。
- **結線（エッジ）:** 2px の落ち着いたソリッドライン。

### 2.2 Visual Stage：リファレンス完全準拠インフォグラフィック・スタジオ

ユーザー提供のリファレンス画像群（15 種以上）に基づき、Visual Stage 起動時に 4 つの本格的なグラフィックデザインスタイルを即座に適用・切替可能とする。

1. **Pastel Shapes（パステルグラデーション図形フロー / リファレンス 1・12 準拠）:**
   - **背景:** ティール〜シャンパン〜ピンクの優美なパステルグラデーション ＋ 半透明ホワイト方眼グリッド。
   - **箱の造形:** 枠線（`stroke`）を完全撤廃。面（サーフェス）としてのソフトドロップシャドウ（`feDropShadow`）を適用。
     - 開始 / 終了ノード: 丸角ピルカプセル（純白、またはライムグリーン〜ミントのグラデーション）。
     - 処理ノード: サンセットアンバー〜ゴールドのグラデーション矩形。
     - 判断・分岐ノード（ひし形）: アクアスカイ〜シアンのグラデーション。
     - 入出力ノード（平行四辺形）: コーラルピンク〜ピーチのグラデーション。
   - **結線:** チャコールグレー（`#334155`）のエディトリアル矢印。

2. **2-Tier Cards（2 段組インフォグラフィックカード / リファレンス 4・6・16 準拠）:**
   - **ヘッダー:** `FLOW CHART // INFOGRAPHIC` タイトルプレート ＋ 4 色バー（Coral, Gold, Periwinkle, Teal）。
   - **箱の造形:** 縦長インフォグラフィックカード。上段にステップ記号（A, B, C...）付きのカラーキャップ、下段に立体ソフトシャドウを持つホワイトボディの 2 層構造。

3. **Vibrant Circles & Dots（サークル＆ドットコネクタ / リファレンス 2・7・13 準拠）:**
   - **箱の造形:** 豊かな 5 色ベタ塗りサークル（テラコッタレッド、スチールブルー、キャメルオーカー、セージグリーン、ディープバイオレット）＋白抜き文字。
   - **結線:** 丸ドット破線（`stroke-linecap: round; stroke-dasharray: 0 10; stroke-width: 4px`）。

4. **Editorial Cream（マガジンチャート風 / リファレンス 3・8 準拠）:**
   - **背景:** ウォームクリーム（`#F7F4EB`）。
   - **箱の造形:** 純白の真円・ピルカプセル ＋ ダスティローズ（`#D68C8C`）のバッジ ＋ セージグリーンの太いフラット矢印。
