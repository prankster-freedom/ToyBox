# テスト仕様: 図の描画と後処理（diagram-rendering）

すべての TC は、`index.html` を `file://` で開き、`sample.md` を読み込んでから実施する。確認方法が「自動」の TC は [tests/e2e.cjs](../../tests/e2e.cjs) で確認する。

「全モード」は次の 7 通りとする: 通常モード Light / Dark、Visual Stage の 4 スタイル（Light）、Visual Stage の Pastel Shapes（Dark）。
